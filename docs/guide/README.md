## 바쁠 때 5분 요약

1. **문제:** 팀원들이 각자 AI를 쓰면서 실험 결과를 공유하다 보면, "피처 12개일 때 XGBoost가 좋았다"가 "XGBoost가 좋다"로 바뀐다. 조건이 사라지고, AI가 한 말이 팀이 합의한 사실처럼 굳어진다.
2. **해결:** AI와 팀 기록 사이에 **하네스**(검문소 같은 중간 프로그램)를 둔다. 기록이 들어올 때 검사하고, 질문이 오면 조건에 맞는 기록만 골라서 AI에게 넘긴다.
3. **비교:** 같은 질문 14개를 네 가지 방식에 던지고 채점했다.
   - 일반 검색
   - 기록 전체를 AI에 넣기
   - Graphiti (이미 있는 유명한 도구)
   - 하네스
4. **결과:**
   - 하네스는 기록이 늘어나도 정확도 100%를 유지했다.
   - 하네스는 AI에게 넘기는 글의 양이 기록 전체를 넣는 방식의 약 0.4%뿐이었다.
   - 하네스만 민감 정보를 한 번도 내보내지 않았다.
   - Graphiti는 기록의 조건과 승인 여부를 잃어버려서 36%에 그쳤다.
5. **솔직한 한계:** 데이터는 우리가 직접 만든 연습용이고 질문이 14개뿐이다. 정확도 차이도 1~2문항이라 "정확도에서 크게 이긴다"고 말할 수는 없다.
