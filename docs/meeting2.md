# 2차 멘토링 발표 흐름

1차 멘토링에서 멘토가 요청한 순서(모티베이션 → 베이스라인 → 메트릭 → 개선 폭 → 효율성)를 따른다.

## 1. 지난 숙제 체크

| 숙제 | 결과 |
|---|---|
| 모듈 구성 확정 | 7개 모듈: 구조화, 인용 검증, PII 차단, 관계 판정, 저장소, 리트리버, 답변 구성 (README 흐름도) |
| 스트롱 베이스라인 | Graphiti 확정, 실제로 실행해서 비교 |
| 메트릭 좁히기 | 메인 1개(condition_match) + 보조 지표 |
| 핵심 모듈 데모 | 동작함 (`python -m eval.run_eval -v`) |
| 효율성 고민 | 모듈별 모델 크기 차등, 인용 검증 캐시, 답변 캐시, 맥락 크기 측정 |

## 2. 모티베이션 (1장)

공유된 문장이라는 이유만으로 근거의 범위가 넓어진다. 범위는 두 가지다.
- **근거의 범위:** 조건, 승인 여부, 재인용
- **공개 범위:** 민감 정보

이 둘을 "공유 범위 제어"라는 한 문제로 본다.

## 3. 실험 설계: 공정 비교 프로토콜 (1장)

- **같은 입력:** 모든 시스템이 기록 원본과 원문만 받는다. 정답 구조는 누구에게도 주지 않는다.
- **같은 답변기:** 같은 LLM(`gpt-6-luna`)과 같은 프롬프트로 답한다. 차이는 기억 계층에서만 난다.
- **비교 대상:**
  - BM25 검색
  - 전체 맥락 LLM: "정보만 다 넣으면 되지 않나?"에 대한 대조군
  - Graphiti: 스트롱 베이스라인
  - 하네스
- **데이터:** 합성 기록 15개 + 조건만 다른 방해 기록 0 / 100 / 300개. 질문 14개.

## 4. 결과 (2~3장)

| 기록 수 | BM25 | 전체 맥락 LLM | Graphiti | **하네스** |
|---|---|---|---|---|
| 정확도 15 / 115 / 315 | 1.00 / 0.93 / 0.93 | 1.00 / 0.86 / 0.93 | – / 0.36 / – | **1.00 / 1.00 / 1.00** |
| 맥락 글자 수 (315개) | 1,611 | 87,026 | 354 (115개) | **330** |
| PII 맥락·답변 (315개) | 0.64 / 0.00 | 1.00 / 0.07 | 0.14 / 0.07 (115개) | **0.00 / 0.00** |

그래프: `docs/figures/context_vs_records.png`

**말할 것**
1. 하네스는 규모와 관계없이 정확도를 유지했다. 전체 맥락 LLM이 쓰는 맥락의 **약 0.4%**만 쓴다. 기록 315개 기준 87,026자 대 330자로 약 260배 차이다.
2. 하네스만 민감 정보를 맥락에도 답변에도 내보내지 않았다.
3. Graphiti는 기록을 사실로 요약하면서 조건, 승인 상태, 작성자 정보를 잃는다.
   - Q02 사례: AI가 올린 승인 전 기록이 팀 사실로 제시됐다.
   - 결과: 0.36. 기록 15개와 115개에서 같았다.

**말하지 않을 것 (질문 받으면 이렇게 답한다)**
- "정확도에서 크게 이긴다"고 하지 않는다. 기록이 적으면 프롬프트를 잘 쓴 LLM도 정확하다. 차이는 1~2문항이라 변동 범위다.
- "Graphiti가 틀린 인용으로 맞는 사실을 덮어쓴다"를 일반화하지 않는다. 1차 실행에서 한 번 관찰됐고, 이후 재현되지 않았다.

## 5. 한계와 다음 단계 (1장)

- **데이터:** 직접 만든 합성 데이터이고 질문이 14개뿐이다. → 실제 팀 실험 로그로 데이터를 만들고, 관계 유형별로 질문을 10개 이상 확보한다.
- **PII:** 실명 판정에 외부 LLM을 쓴다. → 로컬 개체명 인식(NER) 모델로 바꾼다.
- **효율:** 기록 입력 비용을 비교하지 않았다. Graphiti는 115개에 24.4분 걸렸다. → 하네스 입력 시간을 측정한다.
- **열린 질문 (팀 결정):** 승인 절차를 어떻게 할지, 조건 키를 고정할지.

## 6. 멘토에게 물어볼 것

- 정확도 차이보다 효율과 PII 쪽 기여를 앞세우는 방향이 괜찮은가?
- 실제 데이터를 어디서 구하면 좋을까? 사내 회의록이나 실험 로그 같은 공개 데이터셋을 아는지.
- 멘토 팀은 온디바이스 소형 모델을 다룬다. 구조화나 PII 판정을 로컬 소형 모델로 돌리는 구성을 어떻게 보는지.
